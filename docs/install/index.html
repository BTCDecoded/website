Install blvm

Pre-built binaries and Linux packages from GitHub Releases, with checksums.sha256 on every release. Verify before running. Current release: v0.1.36 on GitHub →

Linux package managers

Standalone binaries

Debian / Ubuntu

Ubuntu 22.04+, Debian 11+, and any dpkg-based distro.

Download .deb
Install
sudo dpkg -i blvm_0.1.36_amd64.deb
sudo apt-get install -f    # pull in any missing deps
Verify checksum
# Run in the folder where you saved blvm_0.1.36_amd64.deb
curl -LO https://github.com/BTCDecoded/blvm/releases/download/v0.1.36/checksums.sha256
grep 'blvm_0.1.36_amd64.deb' checksums.sha256 | sha256sum --check

Releases may publish a detached GPG signature beside each artifact (often blvm_0.1.36_amd64.deb.sig). Signature verification guide →

Docker

Official image on GHCR, published on every stable release.

View on GHCR →
Pull
docker pull ghcr.io/btcdecoded/blvm:0.1.36
Run
docker run -d --name blvm \
  -v blvm-data:/data \
  -p 8333:8333 -p 8332:8332 \
  ghcr.io/btcdecoded/blvm:0.1.36

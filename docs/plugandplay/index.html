Start9

Install BTCDecoded directly from the Start9 marketplace. Start9 provides a sovereign personal server with a built-in app store — no command line required.

Installation steps

  1. Open your Start9 dashboard and navigate to the Marketplace.
  2. Search for "BTCDecoded" and select the package.
  3. Click Install and follow the on-screen prompts.
  4. Once installed, configure your data directory and sync settings from the service properties panel.
